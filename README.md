# 🇰🇭 Secondary School Quiz Game

វេទិកាសំណួរអប់រំ Khmer-first សម្រាប់ថ្នាក់ទី ៦–១២។ គម្រោងនេះប្រើ HTML5, CSS3 និង Vanilla JavaScript ហើយមិនមាន backend/database/authentication/API key ទេ។

## របៀបប្រើ
1. បើក `index.html` ក្នុង browser។
2. ជ្រើសថ្នាក់ និងមុខវិជ្ជា។
3. ចុច `✨ សំណួរឧទាហរណ៍` ដើម្បីផ្ទុកសំណួរ ឬបន្ថែមសំណួរផ្ទាល់ខ្លួន។
4. កំណត់ Timer និងជម្រើសផ្សេងៗ។
5. ចុច `🚀 ចាប់ផ្តើមលេង`។
6. សិស្សជ្រើសចម្លើយ ហើយត្រូវចុច `បន្ទាប់ ➜` ដោយខ្លួនឯង។

## លក្ខណៈពិសេស
- Noto Sans Khmer
- Grade 6–12
- 11 មុខវិជ្ជា និងសំណួរឧទាហរណ៍ 5 សំណួរ/មុខវិជ្ជា
- បង្កើត/កែ/លុប/ចម្លង/រៀបលំដាប់សំណួរ
- Image URL + preview ក្នុង quiz
- Timer 15–90 វិនាទី
- Speed bonus រហូតដល់ +5
- Countdown 3 → 2 → 1 → START
- Correct/wrong/timeout feedback
- Fireworks, rockets, confetti-style particles
- Dark/Light mode
- Web Audio API sound effects
- localStorage auto-save
